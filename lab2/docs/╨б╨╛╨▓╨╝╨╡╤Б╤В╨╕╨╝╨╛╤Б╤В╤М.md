# Совместимость

Проект настроен на **JDK 17**, так как он используется в основном курсовом проекте.

JavaFX 21.0.6 оставлен без изменения: эта версия рассчитана на использование с JDK 17+.

Maven compiler release изменён с 21 на 17. Исходный код лабораторной использует конструкции языка, доступные в Java 17.
