# Упрощение интерфейса

В этой версии оформление приложения практически не стилизуется средствами CSS.

- удалена пользовательская тема ;
- отключены декоративные карточки, цветные панели, рамки и эффекты наведения;
- кнопки, поля, списки и таблицы используют стандартный внешний вид JavaFX;
- сохранена функциональность приложения;
- декоративные изображения не используются.

Цель — получить максимально простой учебный интерфейс, чтобы основное внимание было на логике лабораторной работы.
